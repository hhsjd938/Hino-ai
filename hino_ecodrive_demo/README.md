# HINO EcoDrive · Replay Studio

以 **Streamlit 1.65.0 + Components v2 + Web Speech API** 回放歷史車況，展示中文駕駛提醒。Python 一次計算事件時間軸；瀏覽器依時間戳更新畫面，不會每秒重新執行 Streamlit。

## 安裝與啟動

需要 Python 3.10 以上。在專案根目錄執行：

```powershell
.venv\Scripts\python.exe -m pip install -r hino_ecodrive_demo\requirements.txt
.venv\Scripts\python.exe -m streamlit run hino_ecodrive_demo\app.py --server.address 127.0.0.1 --browser.gatherUsageStats false
```

開啟 <http://127.0.0.1:8501>。先按 **測試語音**，再按 **開始 / 繼續**。也可用已啟用環境中的 `python` 取代 `.venv\Scripts\python.exe`。路徑以程式位置解析，因此從 Demo 資料夾啟動也可以。

介面採用米白背景、奶油白卡片與暖棕色操作按鈕。請從專案根目錄啟動，讓 Streamlit 載入 `.streamlit/config.toml`，側欄、原生表格與選單才能套用相同主題；`app.css` 管理共用版面，`dashboard.css` 與 `route_search.css` 分別管理回放元件及路線搜尋頁。

- **真實 HINO 行程**：附帶車輛 `C1N6TWBTVB`、行程 `250731030003` 的小型匯出資料，不需要開啟大型 Excel。
- **模擬情境**：正常、高 RPM、高 RPM 低速、急加速、急減速、長時間怠速、超速。皆明確標示「非真實量測」。
- **1 / 10 / 30 / 60 倍速**：按照資料時間排程；偵測結果不隨倍速改變。模擬怠速在第 300 個資料秒觸發，60 倍速約需 5 個實際秒。
- **暫停**：停止時間及語音、清空待播語音；繼續後不補播舊提醒。重設／切換情境／調整參數將清除本次狀態。
- **背景分頁**：自動暫停，回到頁面後手動繼續。清除畫面事件紀錄不會清除事件統計。
- **行程摘要**：播放完成後顯示事件數、里程、耗油、建議，以及真實行程的同路線群組參考。原始車機事件與自訂事件分開列名；模擬情境不推算油耗。

## 在頁面匯入 CSV／XLSX

選擇左側 **駕駛回放 → 真實 HINO 行程**，在主畫面上方的「行程資料」切換 **上傳 CSV** 或 **上傳 XLSX**，再拖曳檔案或按選檔按鈕。驗證成功後會顯示回放儀表板；也可切回「內建範例」。匯入只在記憶體處理，不覆寫內建 `replay.csv` 或來源 JSON。

CSV 每份檔案限 **20 MB、單一車輛與行程**，需為 UTF-8 CSV，至少兩筆逐筆車況。必填欄位為 `timestamp,speed,rpm,car_status,can_status`；時間需包含日期，車速單位 km/h，`car_status` 為 0 停車／1 行駛／2 怠速，`can_status` 正常為 0。頁面的「支援格式與範例下載」提供可直接上傳的真實範例。

XLSX 上限 **200 MB**，可以直接上傳原始 HINO 活頁簿，無需先執行 `prepare_replay.py`。上傳後選 **工作表 → 車輛 → 行程**；可在同一份檔案切換行程，每次只回放所選的一趟。工作表第一列需為欄位名稱，支援以下兩種格式：

- 原始 HINO 欄位：`time,can.canSpeed,can.engine.rpm,carStatus,can.canStatus`，自動對應 `enabledCode,journeyCode`、累積里程／耗油、GPS 與 `event[0..2]`。
- 回放欄位：與上述 CSV 相同的欄位名稱，另可提供 `vehicle,journey,event_reports` 等選填欄位。

支援 Excel 原生日期儲存格（1900／1904 日期系統）及 ISO 日期時間文字；保留資料真實時間間隔，不重採樣。選錯工作表時會提示缺少的欄位，改選資料表即可繼續。不支援舊版 `.xls`、加密或損毀的活頁簿。

大型 XLSX 首次讀取工作表需等待數分鐘；程式串流解析並將資料分塊壓縮，快取已讀取工作表，切換行程時只解壓相關區塊，不重新掃描整份 Excel。以本機 115 MB 原始 HINO 檔實測，約 128 秒讀取 493,744 筆、3,541 趟行程；範例 `C1N6TWBTVB / 250731030003` 對帳為 413 筆、急加速 2 次、急減速 14 次。耗時會隨電腦而異。

可另外提供 `vehicle,journey,mileage,fuel,speed_limit,longitude,latitude,event_reports`。`mileage`、`fuel` 是累積里程及耗油；`event_reports` 格式沿用下方說明。沒有事件欄位仍可回放車況與自訂高 RPM，但不建立推算的急加減速、怠速及超速車機事件。上傳資料的摘要不套用內建範例的群組油耗比較。`trip_metrics.csv` 這種一趟一列的摘要不能直接回放。

## 共同起終點搜尋

在左側「功能」切換至 **共同起終點搜尋**：

1. 直接填寫起點／終點的緯度、經度；或選擇既有行程，按「帶入所選行程起終點」。
2. 設定兩端各自的搜尋半徑，預設 **1,000 公尺**；可篩選車輛，預設只查通過品質篩選的行程。
3. 按「搜尋共同起終點」，查看符合行程、已驗證路線群組、中位時間與耗油，以及 GPS 軌跡。
4. 可下載本次符合行程 CSV。往返方向分開比對；查回程請按「交換起點與終點」後重新搜尋。

搜尋使用 `data/processed/analysis` 現有的 `trip_metrics.csv`、`route_group_members.csv`、`route_groups.csv`，不掃描大型 Excel，不需要地理編碼或外部搜尋 API。可選範例為車輛 `AHMPUL0C13`、行程 `250111000001`：起點 `(23.050751, 120.265442)` → 終點 `(23.214016, 120.320221)`，1 km 半徑可找到 `AHMPUL0C13-R001` 群組內 36 趟行程。

搜尋沒有要求相近里程，因此共同起終點但繞行距離不同的歷史行程也能列出。尚未分群的行程只標示「僅符合起終點」，不把每趟當成不同道路走法。既有群組依**同車**路徑重疊建立，跨車群組尚未合併；群組數不等於不同道路走法數。

GPS 軌跡讀取既有 `route_stop_map.html` 中的資料，目前涵蓋 999 趟行程。沒有現成軌跡的符合行程只顯示起終點，不繪製推測路徑。預設關閉道路底圖，可直接比較軌跡；勾選道路底圖才會連線至 CARTO 服務。搜尋本身在本機完成。

新增驗證包含方向、兩端半徑邊界、車輛與品質篩選、群組統計、CSV 匯出與既有軌跡解析。Python 共 23 項、Node 9 項測試通過；Streamlit 檢查也涵蓋搜尋結果、地圖資料、反向查詢及無結果情境。地圖的實際瀏覽器視覺呈現仍待人工確認。

## 規則與來源

真實模式沿用原始 `event[0..2]` 的車機回報。依「車輛＋事件代號＋開始時間」去重，**首次收到事件才顯示**；不把未來回報的結束時間提前呈現。其他官方事件僅列在紀錄中；核心事件 2、6、7、8 及自訂高 RPM 可播報。

模擬模式的預設判定如下，數字可在側欄調整。官方規則依本專案的 `Event Type_0929補充.xlsx` 與本次討論指定的急加速解讀實作；它們不表示每台歷史車機當時實際採用的參數。

| 事件 | 觸發 | 解除／重設 |
|---|---|---|
| 急加速 6 | 四筆逐秒速度 V1～V4：**V4−V3 >10 且 V4−V2 >5 且 V3−V1 >5 km/h** | 同類觸發至少間隔 10 個資料秒 |
| 急減速 7 | 四筆逐秒速度：V4−V2 ≤−15 且 V3−V1 ≤−15 km/h | 同類觸發至少間隔 10 個資料秒 |
| 怠速 2 | RPM 不為 0 且車速為 0，累計達 300 秒 | 觸發前速度 >10 或引擎停止歸零；0～10 移動不累計。觸發後速度 ≥10 連續 30 秒或熄火解除 |
| 超速 8 | 速度 ≥路段限速＋10，或 ≥107 km/h，分支各連續 5 秒 | 路段分支速度 ≤限速、固定分支速度 ≤95，各持續 5 秒；全部已觸發分支解除才結束事件 |
| 自訂高 RPM | RPM >2500 連續 5 秒 | 條件不成立解除 |
| 自訂高 RPM 低速 | RPM >2500 且速度 <30 連續 5 秒 | 條件不成立解除；優先於一般高 RPM 提醒 |

真實模式的參數修改不重算車機事件 2、6、7、8，只影響自訂高 RPM 與觀測估計。介面的加速度是 `(本筆速度－前筆速度) / 3.6 / 時間差` 的**區間平均值**，不是車機逐秒加速度。

持續時間只累計兩端皆符合條件的有效觀測區間；預設最大間隔 10 秒。缺值、CAN 異常、重複時間或超過最大間隔會中斷估計，不補值、不跨缺口推斷連續怠速，也不產生虛假的解除事件。真實官方事件仍保留其回報狀態。急加減速的模擬判定必須具有四筆相隔一秒的資料，不重採樣。

高 RPM 規則在兩種模式皆為**自訂規則**。一般及低速高 RPM 各自統計；同時成立時優先顯示／播報低速高 RPM。

## 語音行為

優先順序：急減速 → 超速 → 急加速 → 高 RPM 低速 → 高 RPM → 怠速。一次一段、待播最多三段、同類播報至少相隔 30 個資料秒；播報開始另至少相隔 8 個實際秒。待播內容超過 10 個實際秒就丟棄，避免加速回放後補播過時提醒；API 超過 20 秒未結束會取消。這些限制只影響聲音，**不刪除事件紀錄或次數**。

優先選 `zh-TW`／繁體中文系統語音；其他中文語音可手動選擇。未提供中文聲音、API 不支援、播放遭阻擋或失敗時顯示文字提示，回放繼續。語音來源取決於瀏覽器與系統，不保證離線可用。狀態「API 已完成」不能證明使用者實際聽到聲音，仍需確認喇叭及系統音量。

## 重新匯出真實行程

```powershell
.venv\Scripts\python.exe hino_ecodrive_demo\prepare_replay.py `
  --source "hino\output data_Hotai_20260511.xlsx" `
  --vehicle "C1N6TWBTVB" `
  --journey "250731030003"
```

此工具只讀原始 Excel 的第一張資料工作表，串流擷取指定行程，按欄位名稱對應，不依賴固定欄位位置；不修改原始檔。預設覆寫 Demo 的 `replay.csv` 和 `replay.meta.json`。大型 Excel 掃描需等待數分鐘，進度會顯示在終端機。可用 `--output` 指定另一個 CSV，再從頁面上傳；也可匯出到預設 `replay.csv` 使用內建資料入口。

CSV 欄位：`timestamp,speed,rpm,car_status,can_status,mileage,fuel,speed_limit,vehicle,journey,longitude,latitude,event_reports,source_excel_row`。`event_reports` 是 JSON 陣列，保留該筆原始事件的類型、開始／結束時間與 info 欄位。車速為 CAN km/h；RPM 為圈／分；里程為累積 km；燃油為累積 L。`car_status`：0 停車、1 行駛、2 怠速；CAN 正常值為 0。

來源 JSON 保存原始檔名、SHA-256、CSV SHA-256、行程識別、筆數及既有同路線中位數參考。匯出的兩個檔案應一起更換。里程及耗油以已播放的最後值減第一值；群組耗油偏差使用完整群組（包含本趟）中位數，與原 Trip Behavior 報表相同。

## 測試與驗收

```powershell
.venv\Scripts\python.exe -m unittest discover -s hino_ecodrive_demo\tests -p "test_*.py" -v
node --test hino_ecodrive_demo\tests\frontend.test.mjs
.venv\Scripts\python.exe hino_ecodrive_demo\tests\check_app.py
```

Python 測試涵蓋規則邊界、三條件同時成立、逐秒要求、怠速、超速雙分支、缺口、CAN 異常、事件去重、原始回報時間與既有摘要對帳。Node 測試不需要 npm 套件，涵蓋不規則時間回放、所有倍速、暫停／繼續／重播及語音佇列。Streamlit AppTest 驗證真實模式與七種模擬情境均可載入 Components v2。

瀏覽器實際驗收步驟：

1. 開啟真實模式，按「測試語音」，分別確認 API 狀態與實際聽到中文聲音。
2. 用 60 倍速播完；確認急加速 2 次、急減速 14 次，耗油與原 Trip Behavior 報表一致。
3. 切換模擬情境，逐一確認警告；怠速用 60 倍速快速展示第 300 秒觸發。
4. 暫停後等待、再繼續，確認時間沒有跳過；重設後事件統計歸零；切到背景分頁自動暫停。
5. 關閉語音，確認警告與事件照常；開啟語音後確認不重疊、不補播過時提醒。

本次開發環境沒有可用的瀏覽器控制工作階段，因此**實際畫面、背景分頁行為、中文聲音與聽音驗收仍需依上述步驟確認**。自動測試結果不當作實際聽音證明。

本次驗證紀錄（2026-10-11）：Python 15 項、Node 9 項均通過；Streamlit 真實模式、七種模擬情境及參數修改共 9 項載入檢查通過；原 Trip Behavior 的 6 項測試亦通過。真實範例為 413 筆、7,789 秒、26.9 km、8 L，官方急加速 2 次、急減速 14 次，已對帳。語音排程、完成／失敗回呼以模擬 API 測試通過；**實際瀏覽器 API 播報與實際聽音均尚未確認**。

此 Demo 在本機執行，沒有新增外部 API、LLM、地圖或遠端儲存服務。回放只表示歷史資料與規則展示，不宣稱即時連車或節油因果效果。
